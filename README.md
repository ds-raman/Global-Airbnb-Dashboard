# Global Airbnb Analytics Dashboard

## Overview

The **Global Airbnb Analytics Dashboard** is an interactive Power BI project designed to analyze Airbnb listings and transform raw data into meaningful business insights. The dashboard provides a comprehensive view of listing performance, host activity, customer ratings, and review trends through interactive visualizations.

This project demonstrates practical data analytics skills including data cleaning, transformation, data modeling, DAX, and dashboard development using Microsoft Power BI.
